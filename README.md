# restfulapi-examples

Working code examples for the tutorials on [restfulapi.net](https://restfulapi.net/).
Each folder is one article. Every example is built and run before the article is published,
and each folder has its own README with the versions used and the run commands.

| Folder | Article |
|---|---|
| [mcp-vs-rest-api-example](mcp-vs-rest-api-example/) | [MCP vs REST API: How to Turn a REST API into an MCP Server](https://restfulapi.net/mcp-vs-rest-api/) |
| [token-based-rate-limiting-example](token-based-rate-limiting-example/) | [Token-Based Rate Limiting for LLM and AI Agent APIs](https://restfulapi.net/token-based-rate-limiting-llm-apis/) |
